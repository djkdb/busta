# 문제 정의와 MVP

## 사용자와 문제

시외버스로 이동하며 도착 이후 일정을 계획하는 사람은 고정된 소요시간보다 해당 날짜·출발시간의 현실적인 도착시간을 알고 싶다. 이 서비스는 시간표를 복제하기보다 출발시간에 따라 달라질 수 있는 이동시간을 비교한다.

## 가설

소요시간 차이와 도착시간을 나란히 보여주면 사용자가 출발시간을 비교하기 쉽다. 아직 사용자 조사나 실제 운행 데이터로 검증한 가설은 아니다. 초기 프로토타입으로 입력·비교 경험을 검증한 뒤 실제 데이터의 확보 가능성을 조사한다.

## 첫 MVP의 완료 조건

1. 출발지·도착지·날짜·시간을 선택해 결과를 얻는다.
2. 예시 기준 시간, 예상 소요시간, 차이, 도착시간이 한 화면에 보인다.
3. 시간대별 차이를 그래프와 표로 비교하고 다른 시간을 선택한다.
4. Mock임을 상단, 결과, 데이터 설명에서 명확히 알린다.
5. 잘못된 입력과 자정·월말·연말 경계를 검증한다.
6. 데스크톱과 모바일 브라우저에서 실제 사용자 흐름을 확인한다.

## 제외한 범위

예약·결제·회원 가입·위치 추적·실제 배차·공식 시간표·실시간 API·ML·정확도 표시는 포함하지 않는다. 도착 목표시간 검색은 다음 제품 단계로 남긴다.

## 대회와 연결

중간 발표는 문제·데이터 정직성·AI 개발 워크플로우·MVP 시연을 중심으로 구성한다. 최종 발표 전에는 실측 데이터의 가용성을 판단하고, 확보된다면 검증용 데이터 분리와 오차 측정 과정을 기록한다. 수집하지 않은 통계나 진행하지 않은 사용자 조사를 성과로 제시하지 않는다.
