## 구현 중 구체화한 기준 (AI의 설계 결정)

아래는 사용자가 별도로 보낸 v2 프롬프트가 아니라 v1의 모호함을 해결한 구현 결정이다.

- “공식 소요시간”은 출처가 확보되지 않아 “시간표 소요시간 · 예시”로 표시한다.
- 무작위 지연 대신 평일·주말의 명시적인 시간별 계수와 보간을 사용한다.
- 모든 시간을 한국 기준으로 처리하고, 자정을 넘으면 다음 날 표시를 붙인다.
- 그래프 막대는 실제 배차가 아니라 시간 시뮬레이션으로 표시한다.
- 현재 입력과 마지막 결과가 다르면 재검색 안내를 보여준다.
- Mock 시뮬레이션과 학습된 AI 모델을 명확히 구분한다.

## 앞으로의 프롬프트 개선 포인트

실제 데이터 단계에서는 “교통 API를 연결해”만으로 진행하지 않는다. 데이터 출처·라이선스·노선 매핑·과거/미래 시간 지원·실패 응답·검증 표본을 추가 입력으로 받아야 한다. 실제로 그런 개선 요청과 결과가 생기면 이 파일에 다음 버전으로 기록한다.
