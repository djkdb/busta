# AI 협업 워크플로우

## 사용한 도구와 역할

- 사용자: 해결할 문제, 대회 기준, 데이터 정직성 원칙과 완료 조건을 자연어로 제공.
- Codex: GitHub 조사, 설계, 코드·테스트·문서 구현, 오류 수정 및 실행 검증.
- GitHub 플러그인: 실제 레포지토리 검색·구조 조회와 변경 검토 경로.
- 로컬 Node/npm/Git: 재현 가능한 의존성 설치와 빌드·테스트.
- Vitest / Playwright: 도메인 경계 및 실제 브라우저 사용자 흐름 검증.

원본 요구사항에 Claude Code가 언급되지만 이번 구현에 사용한 AI는 Codex다. 사용하지 않은 도구를 활용 실적으로 기록하지 않는다.

## 작업 순서

요구사항 읽기 → 레포지토리 확인 → MVP/데이터 계약 설계 → 구현 → lint/타입/단위 테스트 → production build → 실제 브라우저 검증 → 문서화 → 변경 검토.

## 역할 분담 원칙

AI는 코드를 생성한 뒤 자기 검증으로 끝내지 않고 독립적인 기대 결과를 테스트로 명시한다. 예: 금요일 17시, 가상 기준 100분, 계수 1.28이면 19:08 도착. 실제 예측 정확도는 별도 데이터 없이는 평가하지 않는다. 사용자는 이후 실제 데이터 사용 가능성과 제품 우선순위를 결정한다.

## 기록 원칙

발생한 실패만 트러블슈팅에 기록한다. 사용자 원문·AI가 세운 가정·검증 사실·향후 계획을 구분한다. 원문 지침은 initial-brief.txt, 중요한 결정은 prompt-log.md, 실행 결과는 validation.md에 남긴다. 이 요약은 원본 채팅 전체가 아니며 대회용 AI Chat Log는 별도로 내보내야 한다.
